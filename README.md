SaveQuest -- A Gamified Personal Finance Assistant

-->Project Overview:
SaveQuest is a gamified personal finance web application designed to
help users develop better saving habits through interactive financial
goals, challenges, rewards, streaks, levels, and leaderboards. Instead
of treating personal finance as a purely numerical task, SaveQuest uses
game-inspired mechanics to encourage consistent participation and
progress.

-->Problem Statement:
Many students and young adults find it difficult to maintain consistent
saving habits. Conventional finance trackers mainly focus on recording
transactions, budgets, and reports, but may not provide enough
motivation for continued engagement. SaveQuest addresses this gap by
combining personal finance management with gamification.

-->Objectives:
.Encourage consistent saving habits.
.Allow users to create and monitor savings goals.
.Convert saving activities into interactive challenges.
.Reward users for completing financial tasks.
.Maintain motivation through XP, streaks, badges, and levels.
.Provide leaderboard-based social engagement.
.Offer a simple and user-friendly finance interface.
.Provide a foundation for future intelligent financial assistance.

-->Key Features:
User Authentication
Users can register and log in to access their personalized SaveQuest
account.

-->Savings Goals
Users can define financial goals, such as saving a specific amount
within a selected period.

-->Saving Challenges
Users can participate in challenges such as No-Spend Days, fixed-amount
saving tasks, and spending-control missions.

-->Gamification:
SaveQuest uses: - XP points - Levels - Streaks - Badges - Titles -
Rewards - Missions - Leaderboards

-->Progress Tracking
Users can monitor their goals, challenges, XP, streaks, and
achievements.

-->Leaderboard
The leaderboard provides a social component by allowing users to compare
progress using the application's scoring system.

-->Major Modules:
1. Login and Authentication Module
Handles registration, login, authentication, and access control.

2. Dashboard Module
Displays an overview of goals, challenges, savings progress, XP,
streaks, and achievements.

3. Goals Module
Allows users to create, monitor, update, and complete savings goals.

4. Challenges Module
Provides missions that encourage disciplined spending and saving.

5. Rewards Module
Manages XP, badges, titles, and achievement information.

6. Streak Module
Tracks consecutive participation and supports consistency-based rewards.

7. Leaderboard Module
Displays users according to their gamification progress and points.

8. User Profile Module
Displays user-specific information and progress.
